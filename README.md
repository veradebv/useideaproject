# IdeaProject (`useideaproject.com`)

AI-powered venture blueprint generator and interactive site builder powered by Next.js, Tailwind CSS, and Gemini 3.8 Flash.

![IdeaProject Studio Preview](./public/preview.png)

## Workflow
1. **Business Model** — Choose a business model, describe your venture idea, and set brand colors.
2. **Blueprint Gate** — Review and customize AI-generated value propositions, pricing tiers, and embedded concierge settings.
3. **Agent Studio & Publish** — Preview desktop/mobile layouts and deploy live in one click via Vercel.
